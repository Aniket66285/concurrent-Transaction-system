ALGORITHM SIMULATOR
Priority rule: smaller number = higher priority

Process input table

Arrival Time, Burst Time and Round Robin quantum use abstract simulation time units—not real wall-clock seconds. Priority is used by Priority scheduling.

PROCESSARRIVAL TIME (AT)BURST TIME (BT)PRIORITYQUEUE (MLQ)ACTION
MLQ policy: Queue 0 = highest priority (Round Robin, quantum 2), Queue 1 = medium priority (Round Robin, quantum 4), Queue 2 = lowest priority (FCFS). Higher queues preempt lower queues. MLFQ policy: every process starts in Queue 0; using its full quantum demotes it to the next queue (2/4/8), with a global priority boost every 30 time units. These are explicit teaching variants.
